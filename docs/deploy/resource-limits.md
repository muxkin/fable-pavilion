# 可选资源额度（Lago）

VPS/Node 与 Cloudflare 两种部署共享同一套资源策略接口（`ResourcePolicyProvider`、`ResourceService`）。是否启用会员空间与月中转流量额度完全取决于实例配置，与部署平台无关。

未配置资源策略提供方时，站点保持无配额的自托管模式；用户仍可使用设置页的一键解密导出与手动清理功能。

## 1. 部署并初始化 Lago

项目在 [`deploy/lago/`](../../deploy/lago/README.md) 中提供了可选的自托管 Lago 部署模板与初始化脚本（仅用于作为权益目录，不包含支付结算或自动扣费）。

1. 按 [Lago 部署说明](../../deploy/lago/README.md) 启动自托管 Lago 实例并登录管理后台。
2. 运行初始化脚本创建基础特性（Entitlements）与初始计划模板（可按你的运营需求在 Lago 后台任意修改名称与数值；脚本不会覆盖已存在的权益配置）：
   - `storage.max_bytes`：附件存储空间上限（整数，十进制字节）。
   - `relay.max_bytes`：自然月中转流量上限（整数，十进制字节）。
   - `relay.time_zone`：用于按月归零计数的 IANA 时区（例如 `Asia/Shanghai` 或 `UTC`）。
3. 只有默认计划会在用户首次触发资源操作时自动懒分配（以 `<instance>:<uid>` 关联）；更高档位由管理员在 Lago 后台按需调整。

> 在 Lago 后台修改计划或订阅覆盖（Override）后，应用会在 60 秒内的下一次资源操作时自动刷新策略。账期内请保持 `relay.time_zone` 稳定，变更时区会切换自然月账本。

## 2. 在应用实例中启用

在 Node 私有环境文件或 Cloudflare Worker 的 `vars` / `secrets` 中配置以下四项（省略全部四项即关闭额度限制）：

```dotenv
POCKET_LAGO_URL=https://billing-api.example.com
POCKET_LAGO_API_KEY=<服务端密钥，切勿暴露给前端>
POCKET_LAGO_DEFAULT_PLAN=<你的默认计划代码>
POCKET_RESOURCE_INSTANCE=<稳定且唯一的实例标识>
```

- `POCKET_RESOURCE_INSTANCE` 用于隔离不同站点的用户 UID 命名空间，上线后应保持稳定。
- 当 Lago 暂时不可达时，已缓存的有效策略最多继续使用 60 秒；过期后新的上传与中转帧会安全失败关闭（fail closed），已存消息阅读、解密下载与手动清理仍保持可用。

## 3. 存储空间计量与手动清理

- **计量范围**：计入账号及其名下所有 Agent 拥有的加密附件原件（含认证标签）、收藏表情与头像；同一计费主体内共享的物理对象仅计一次。纯文本消息、加密账号元数据与数据库索引开销不计入附件空间。
- **超限行为**：上传前在事务中预留空间；空间不足时拒绝新上传（HTTP 413），**不会自动删除已有文件**。
- **客户端一键导出与清理**：
  - **一键下载（解密）**：在浏览器端完成下载、验签解密与明文长度核对，按约 128 MiB 分卷打包为 ZIP（不向服务器上传任何明文或密钥）；对于当前客户端无权解密的条目会在报告中明确列出。
  - **一键清理**：经用户确认后逻辑移除所选历史附件、表情或头像，并由后台持久化队列异步重试清理底层 R2 / 对象存储物理对象；已发送消息正文、加密信封、账号密钥与当月已消耗中转计数保持不变。

## 4. 自然月中转流量计量

- **计量范围**：统计经云端中继转发的 **WSS 加密二进制载荷**（上下行均计一次）；文本信令、WebRTC 直连流量与 HTTP 附件传输不计入。
- **授权与持久化**：客户端须凭有效账号会话换取短时一次性中继授权；计数在服务端原子持久化（跨重启与 Durable Object 休眠生效），不信任客户端上报的字节数。撤销登录会话会同步终止中继权限。
- **超限行为**：超出当月额度的新转发帧会在转发前被拒绝并提示原因；删除已上传文件不会重置当月已消耗的中转流量，下一个自然月开始时自动清零计数。已建立的 WebRTC 直连可继续通信，但新建直连仍需中继信令可达。
