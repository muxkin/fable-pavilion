# 使用指南与能力范围

子虚亭界面围绕 **消息 / 联系人 / 工作台 / 我的** 四个核心模块组织：桌面端导航常驻左侧；手机端在一级页面显示底部导航，进入具体会话或详情页后自动隐藏，留出更大阅读与输入空间。

## 一、工作台：接续电脑上的 Agent 会话

### 浏览与恢复会话

- 在「工作台」可查看已授权电脑上的各个 Agent 实例卡片与最近会话，支持按「最近」和「项目」分组浏览，以及按标题或项目名搜索。
- 已在桌面端加载的会话可直接实时控制；仅存历史记录的会话先以只读方式展示，点击「继续此会话」即可通过桌面原生接口恢复连接后再发送消息。
- 宽屏查看工作台会话时，左侧提供紧凑的**提问刻度导航**，悬停可预览历史提问、点击快速跳转（窄屏自动隐藏）。

### 发送、追加、排队与中断

| 操作 | 交互方式 |
| --- | --- |
| 发送消息 | 空闲时输入内容后点击发送按钮（桌面端 `Enter` 发送，`Ctrl+Enter` / `Shift+Enter` 换行，已兼容中文输入法选词；手机端回车换行、点击按钮发送）。 |
| 运行中追加指令 | 任务执行期间，输入文字或添加附件后直接点击发送，即可向当前任务追加内容。 |
| 排队下一轮 | 任务执行期间，长按发送按钮（或桌面端 `Alt+Enter`）将文字消息排入下一轮；可在右上角 `…` 菜单查看或移除队列项。 |
| 中断当前任务 | 清空输入框后点击暂停图标，即可中断当前回合。 |
| 切换模型与速度 | 点击输入框下方的模型名称，调整模型、推理强度与速度，并应用到下一轮。 |
| 计划模式、技能与插件 | 打开输入框旁的「工具」菜单切换计划模式，或选择本机已安装的技能与插件随下一条消息发送。 |

- **可靠的发送状态**：发送进度直接体现在按钮上，确认送达后自动清空草稿；遇到网络波动导致「结果待确认」时，会保留草稿并提供「核对状态」入口，避免重复提交。
- **草稿保留**：每个会话的文字、已上传附件及技能选择在切换会话和刷新页面后都会保留。

### 提问、审批与计划确认

- **提问卡片**：点击「回答」逐题选择或手填，支持多题切换与提交前核对。
- **审批卡片**：命令执行、文件修改或工具调用审批会展示目标命令、路径或 Diff，核对后可选择允许或拒绝。
- **计划卡片**：支持「批准并执行」进入执行模式，或「提出修改」通过输入框反馈调整意见。

### 富内容与附件

- 支持 Markdown、代码高亮与一键复制、KaTeX 数学公式（点击公式可复制 LaTeX，框选文字与公式时自动保留完整公式分隔符）、Mermaid 图表与 Diff 展示。
- 点击输入框左下角 `＋` 或直接粘贴剪贴板图片上传附件，单次最多 10 个附件、单文件上限 256 MiB，支持分块校验与断点续传。
- 图片查看器支持双指缩放、双击放大、拖动与滚轮缩放（100%–600%），操作不会误触整页缩放。
- 工具活动默认折叠，点击可按需展开命令输出、文件修改与工具查看过的图片。

### 自定义实例外观

点击工作台实例卡片右侧的设置按钮，可自定义该实例的名称、说明和图标（内置图标、Emoji 或自定义图片，最大 5 MB），修改会同步至同一主机的其他已配对设备，不影响底层实例 ID 与会话数据。

## 二、即时消息、联系人与实时通话

### 个人账户与 Agent 接入

- 注册账号无需手机号或邮箱，注册后会获得永久数字字符串 **UID** 与唯一 `@用户名`。
- 默认配置下，系统仅允许个人用户与自己邀请的 Agent 通信；在「联系人 → 接入 Agent」可生成 15 分钟有效的一次性邀请，将说明交给 Agent 即可完成接入（如需开启账号间社交功能，由实例管理员按部署文档显式启用）。
- 在「消息」中支持单聊与 2–50 人群聊，支持流式回复、随时停止生成、引用回复、@ 提及、客户端解密搜索、未读计数与已读回执。

### 表情、语音与交互卡片

- **Emoji 与表情包**：支持搜索 Emoji、管理跨设备同步的个人表情收藏（PNG/JPEG/GIF/WebP，单张上限 2 MiB，最多 50 个）。
- **语音消息**：支持按住或点击录音（最长 2 分钟）、上滑取消、试听与重录，复用共享音频播放器播放。
- **问题与授权卡片**：Agent 可在聊天中发起结构化提问或一次性操作授权卡片，仅指定接收人可作答，结果经端到端签名验证。

### 实时音视频通话

- 在与自己 Agent 的一对一会话标题栏点击「语音」或「视频」即可发起 WebRTC 实时通话。
- 发起前会显示 Agent 的在线接听能力；通话中支持静音、开关摄像头、查看时长与挂断。离开页面或挂断时自动释放摄像头与麦克风。

### 消息与来电通知

- 登录后在「我的 → 设置 → 通知设置」可为当前设备开启系统通知。
- 当会话正处于当前前台视图时，由页面直接更新；处于后台或未打开时，系统通知可直接跳转至对应会话。
- **网页端**使用标准 Web Push（iOS / iPadOS 需先通过浏览器「添加到主屏幕」以 PWA 方式打开）；**Android 客户端**使用 UnifiedPush（需安装并启用站点支持的分发器，例如 ntfy）。退出登录或移除设备会自动撤销订阅。

## 三、外观、离线缓存与设备管理

- **主题与图标**：在「我的 → 设置 → 外观」可切换日夜模式与自定义颜色主题（基于 Material Color Utilities），并支持 JSON 导入导出（最多保存 40 个自定义主题）；应用图标默认「乌有」，亦可切换其他内置样式。
- **离线缓存**：会话历史与附件优先命中本地缓存；电脑离线时仍可浏览已缓存内容。可在「我的 → 设置 → 清理缓存」查看当前占用并手动清理（清理不会解除设备配对，也不会删除草稿和未确认操作）。
- **已授权电脑与安全**：在「我的 → 我的设备」可切换或解除电脑授权；在「我的 → 登录与安全」可查看内置动态码、生成/扫描登录二维码以及管理通行密钥与恢复码。

## 四、各 Agent 支持范围与边界

不同 Agent 产品的底层能力由对应的原生插件提供，运行时以实际连接后的能力声明为准：

| 能力 | Codex | DSH | Antigravity |
| --- | --- | --- | --- |
| 项目列表、历史与实时同步 | 支持（含大历史分页与 zstd 压缩历史） | 支持 | 支持（超大记录自动分页） |
| 发送、新建会话、中断与排队 | 支持 | 支持 | 支持 |
| 运行中追加与改名 | 支持 | 支持 | 支持（追加作用于下一次调用） |
| 模型、推理强度与计划模式 | 支持 | 支持（含 Agent 预设与权限档位） | 支持下一轮模型选择 |
| 技能与插件选择 | 支持本机已安装项 | 支持原生技能目录 | 支持当前会话可用技能与已启用插件 |
| 提问与审批 | 命令/文件审批、计划确认、同步与异步提问 | 单次工具审批、同步与补答提问 | 单选/多选/手填提问、单次命令审批 |
| 附件收发 | 图片与通用文件（单文件上限 256 MiB） | 图片、通用文件与 ZIP 日志导出 | 已有会话图片（每条最多 10 张，合计 32 MiB） |
| 账户用量与语音 | 标题栏查看用量、支持 Codex Voice | — | 工作台查看原生模型组额度与重置时间 |

### 已知限制

- 发送新消息或读取最新进展时，电脑及对应的桌面 Agent 需要保持运行。
- 仅支持选择本机已安装的技能和插件，不支持在手机端安装管理或渲染所有第三方专用 UI。
- 部分尚未适配的原生权限弹窗、MCP 表单、全局规则或超大历史中的写操作，仍需回到电脑端原生应用处理。
- macOS 与 Windows 的部分原生桌面连接能力仍处于持续验证阶段，如遇兼容性问题欢迎附版本信息提交 Issue。
