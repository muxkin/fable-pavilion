# 产品标识图标说明

本目录包含用于在工作台区分已连接 Agent 产品的标识图标。这些图标仅用于识别用户本机连接的产品，不代表项目品牌，也不暗示任何官方关联或赞助；相关名称与商标归各自权利人所有。用户在工作台设置的自定义图片、Emoji 或内置图标始终优先显示。

- `codex.png`：Codex 产品标识（[Codex](https://openai.com/index/introducing-the-codex-app/)、[Brand Guidelines](https://openai.com/brand/)）
- `antigravity.png`：Antigravity 产品标识（[Antigravity](https://antigravity.google/)）
- `dsh.svg`、`dsh-dark.svg`：DeepSeek Harness 浅色/深色标识（[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/web/public/favicon.svg)）
- `claude.svg`：Claude 标识（[Claude](https://claude.com/icon.svg)）
- `openclaw.svg`：OpenClaw 标识（[OpenClaw](https://github.com/openclaw/openclaw/blob/main/ui/public/favicon.svg)）

SVG 资源仅作为外部图片引用，不直接注入 DOM，也不对原图做重新配色或重绘。
